## Installation

1. Clone the repository:
```bash
git clone https://github.com/nikita-stepanov04/ABP_TestAssignment
```
2. Navigate to the project directory:
```bash
cd ABP_TestAssignment
```
3. Navigate to the (`ABP_TestAssignment.Web`) directory and update the configuration file (`appsettings.json`) with the required values. An example configuration file is available on SharePoint alongside the test assignment document. 

4. Build and run the Docker containers:
```bash
docker compose up -d
```
